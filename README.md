# 🪐 InterSpace Board

**A lightweight, standalone visual whiteboard for brainstorming, mind mapping, and branching storytelling.**

An independent, privacy-friendly alternative to Miro and Obsidian Canvas. Works completely offline in a single HTML file — zero dependencies, zero installation.

[🚀 **Try Live Demo**](https://alekshood.github.io/Inter-Space-Board/) · [Report Bug / Request Feature](https://github.com/AleksHood/Inter-Space-Board/issues)

---

![InterSpace Board Main Canvas](screenshots/main%20board.png)

## ✨ Highlights

* **100% Client-Side & Private:** All data stays in your browser (`localStorage`). No accounts, no subscriptions, no trackers.
* **Single-File Portability:** The entire application runs from a single `.html` file. Double-click and work anywhere.
* **Branching Story Mode (RC Mode):** Built-in scene/stage numbering designed specifically for visual novel writers, narrative designers, and game storyboards.
* **Smart Connectors:** Cubic Bezier curves with 6 arrow styles (Classic, Dashed, Hollow, Diamond, Dot, Plain Line) and automatic port snapping.
* **Rich Typography & Marker Tool:** 50+ Google fonts, in-place text styling (Bold, Italic, Underline, Highlighter), freehand drawing, and a geometric eraser.
* **Focus Mode (Alt-Zoom):** Press `Alt` on any block to open a distraction-free, large-print modal editor.
* **Multi-Sheet Workspaces:** Organize complex projects across multiple tabs with independent viewports.
* **Bi-lingual Interface:** Seamless one-click switching between English and Russian (UI + starter templates).

## ⚡ Quick Start

### Option 1: Use Online (No Install)
Open the [Live Demo](https://alekshood.github.io/Inter-Space-Board/) in any modern browser.

### Option 2: Run Offline
1. Download `index.html`.
2. Double-click the file to open it in your browser.
3. Everything works completely offline!

## ⌨️ Shortcuts & Navigation

| Action | Shortcut |
| :--- | :--- |
| **Pan Canvas** | Left-Click + Drag on empty canvas |
| **Zoom In / Out** | Mouse Wheel (or Top Zoom Panel) |
| **Multi-Select** | Right-Click + Drag selection box |
| **Focus Mode (Modal)** | Press <kbd>Alt</kbd> (or <kbd>Esc</kbd> to exit) |
| **Copy / Duplicate** | <kbd>Ctrl</kbd> + <kbd>C</kbd> / <kbd>Ctrl</kbd> + <kbd>V</kbd> |
| **Delete Block / Edge** | <kbd>Delete</kbd> or <kbd>Backspace</kbd> |
| **Undo / Redo** | <kbd>Ctrl</kbd> + <kbd>Z</kbd> / <kbd>Ctrl</kbd> + <kbd>Y</kbd> (up to 50 steps) |
| **Snap Arrow Endpoints** | Drag an arrow end near any block port |
