
# InterSpace Board

**A lightweight, customizable whiteboard for brainstorming, visual thinking, and organizing ideas.**

An alternative to Miro focused on simplicity, flexibility, and essential functionality.

## Features

### Visual Workspace
- **Multiple pages** - create and manage multiple pages within a single workspace.
- **Content blocks** - create blocks with or without titles.
- **Freeform text** - place text anywhere on the canvas.
- **Image support** - add images directly to the canvas.
- **Shape customization** - transform blocks into different shapes.
- **Freehand drawing** - sketch, annotate, and highlight ideas using the marker tool.

### Typography & Styling
- **Text customization** - adjust fonts, sizes, and colors.
- **Font selection** - choose fonts for your content.
- **Default font settings** - configure separate default fonts for headings and body text.
- **Block outlines** - customize block borders and visual appearance.

### Local Storage & Export
- **JSON export** - save your board as a JSON file directly to your computer.

### Visual Narrative Mode
- **Chronological sequencing** - assign sequence markers to blocks to define the order of a visual narrative.
- **Structured JSON output** - export sequenced blocks in chronological order as part of the JSON file.

## Philosophy

**Less clutter. More clarity.**

InterSpace Board provides a flexible visual workspace with the essential tools you need, without unnecessary complexity.
